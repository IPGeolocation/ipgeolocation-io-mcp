IPGeolocation.io

Connect your MCP client

Use IPGeolocation.io tools in your assistant without running an MCP server on your computer.

Connection settings

Your client must support Streamable HTTP and private custom headers.

Server URL

https://mcp.ipgeolocation.io/mcp

Connection type
Streamable HTTP
Header name
X-IPGeolocation-API-Key
Header value
Your IPGeolocation.io API key

Keep your key in your client's private connection settings. Keep it out of chat messages, URLs and shared files.

Get started

  1. Use your existing API key, or create a free account to get one.
  2. Add a remote MCP server in your client using the connection settings above.
  3. Save the connection and ask: Where is 8.8.8.8 located?

Your existing free or paid plan and API credit rules apply. Hosted MCP provides 16 tools for IP location, company and network information, ASN data, security, abuse contacts, time zones, astronomy, currency and user-agent parsing.

Include the IP address or other input you want to look up. The get_my_ip tool is available only in local MCP because a hosted server would return its own IP address.
